# Цветы по коду 🌷

Мобильное веб-приложение: отправитель собирает виртуальный букет, пишет сообщение и получает код. Получатель вводит код и открывает подарок.

## Что уже сделано
- Адаптивный интерфейс для телефона и компьютера.
- Кликабельный выбор 6 цветов, включая подсолнухи 🌻.
- Валидация формы, генерация шестизначного кода, копирование кода.
- Анимация появления подарка и лепестков.
- Режим локального демо без настройки сервера.
- Подключение Supabase для общих подарков между устройствами.
- Дружелюбные ошибки, если код не найден или сервер не настроен.

## Запуск локально
Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`).

## Включить общие коды между устройствами
1. Создай проект в Supabase.
2. Открой SQL Editor и выполни `supabase.sql`.
3. Скопируй Project URL и anon/public key в `.env` на основе `.env.example`.
4. Перезапусти `npm run dev`.

Без `.env` приложение работает в локальном демо-режиме. В демо подарки сохраняются только в этом браузере и не доступны другому устройству.

## Публикация на GitHub + Vercel
1. Создай пустой репозиторий на GitHub и загрузи туда файлы проекта.
2. В Vercel выбери Import Project и подключи репозиторий.
3. В настройках проекта Vercel добавь `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. Нажми Deploy.

Vite автоматически собирает проект командой `npm run build`; папка результата — `dist`.

## Важное перед публичным запуском
Текущий SQL — MVP-заготовка: коды являются секретными ссылками, но политика чтения разрешает чтение строк через клиент Supabase. Для публичного продукта лучше заменить её на PostgreSQL RPC, которая принимает код и возвращает только совпадающий подарок, добавить rate limiting и ограничение частоты создания подарков. Не размещай service-role key в браузере или в GitHub.
